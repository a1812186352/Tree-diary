# 绘木小札（Doodle Tree Diary）

[中文](README.md) | [English](README.en.md)

## 项目简介

一部充满魔法的绘本，一颗承载阳光雨露成长的树木……

**绘木小札（Doodle Tree Diary）** 邀请你走进一场与自然的互动：收集阳光和雨露，自由选择枝叶生长的姿态，让一株树苗按你所希望的样子长大。保卫你的树干，招徕动物朋友，他们会在夜晚帮你抵御虫害。游戏以鼠标移动、点击和拖放为主要操作，用一片片枝条贴纸写下属于这棵树的成长日记。
每一页都是新的一天。白天用有限资源安排生长，黄昏迎接动物伙伴，夜晚由伙伴帮助树木抵御虫害。新贴上的枝条要等翻页后才会成熟，今天的选择也会影响明天可以延伸的方向。当前试玩以六天为一局，目标是在最后一夜结束时仍保有爱心。

- **绘本呈现**：封面、开场视频、故事插画与翻页过渡串联整个体验。
- **枝条拼接**：通过拖放和鼠标朝向安排生长，在可用芽点、资源与空间之间作选择。
- **动物陪伴**：地面伙伴与小鸟分别应对不同虫害。
- **可移动视角**：缩放和拖动画面，观察树从根部向外生长。

## 下载与启动

### Windows 玩家

游戏发布包为 **Windows 64 位便携版**，无需安装 Godot。

1. 前往 [Releases](https://github.com/a1812186352/Tree-diary/releases) 查找作者提供的 Windows 发布包。若尚未提供下载文件，请使用下方的源码运行方式；仓库中的 **Code → Download ZIP** 是源码，不是可直接游玩的安装包。
2. 下载发布包并完整解压到一个文件夹。
3. 确保下面两个文件放在同一目录，然后双击 EXE 启动：

```text
Doodle Tree Diary(winx86).exe
Doodle Tree Diary(winx86).pck
```

当前文件名虽然用godot导出显示 `winx86`，实际程序为 **x86_64（64 位）**。请保留 EXE 与 PCK 的相同文件名前缀，不要只复制 EXE，也不要直接在压缩包内运行。

> 当前发布程序未做数字签名。遇到安全提示时，请先核实下载来源和具体提示；若杀毒软件报告了明确的威胁名称，请将软件名称、威胁名称及截图反馈给作者，不要直接关闭防护。

### 从源码运行

1. 克隆仓库，或使用 **Code → Download ZIP** 下载并解压源码：

   ```bash
   git clone https://github.com/a1812186352/Tree-diary.git
   ```

2. 使用 **Godot 4.7.2** 打开项目（当前工程使用的版本），在项目管理器中选择“导入”，找到 `project.godot`。
3. 等待首次素材导入完成，按 **F5** 运行完整游戏。

主入口是 `scenes/opening/book_opening.tscn`。工程采用 Forward Plus 渲染，需使用支持该渲染器的设备和显卡驱动。运行源码不需要 Godot AI、MCP 或其他开发插件。

## 怎么玩

### 翻开绘本

- 在封面点击“开始阅读”，也可以按 **Enter / 空格**。
- 点击“跳过开篇”可以跳过开场视频，进入故事页。
- 故事页点击翻页按钮，或按 **Enter / 空格 / 方向键右**；最后一页进入第一天。

### 陪树度过六天

你的目标是在六天结束时仍保有爱心。初始有 **3 颗爱心**，爱心耗尽则结束本局。

- **白天（40 秒）**：点击场景中的阳光和水滴收集资源，再从右下方托盘拖出枝条，连接树上空闲的芽点。
- **黄昏（10 秒）**：观察伙伴到场。生长产生的橡果、羽毛预兆与后续动物伙伴有关。
- **夜晚（30 秒）**：动物伙伴自动应对虫害；地面伙伴处理地面虫，小鸟处理飞虫。
- **翻页迎接新一天**：新放置的枝条成熟，其芽点开放，才能继续向外生长。

每天提供 **6 份阳光和 6 份水滴**，未用资源不跨日保留。单芽、双芽、三芽枝条分别消耗 **各 1 / 2 / 3 份阳光与水滴**。每个芽点只能连接一根子枝，尚未使用的芽点会保留到后续天数。

## 操作说明

| 操作 | 方法 |
| --- | --- |
| 收集阳光、水滴 | 鼠标左键点击 |
| 放置枝条 | 左键按住托盘中的枝条，拖到空闲芽点附近后松开 |
| 调整枝条方向 | 拖动时移动鼠标，枝条围绕吸附芽点朝向鼠标 |
| 取消正在拖动的枝条 | 鼠标右键 |
| 取回当天未成熟的枝条 | 在枝条连接处附近右键，返还资源；成熟枝条不可取回 |
| 缩放视角 | 鼠标滚轮，以鼠标位置为中心缩放 |
| 平移视角 | 按住鼠标中键拖动 |
| 回到初始视角 | 双击鼠标中键 |
| 暂停 / 关闭菜单 | Esc，或使用画面顶部按钮 |
| 重新开始 | 使用菜单或结局画面的“再种一棵”按钮 |

枝条预览偏绿色表示当前位置可放置，偏红色表示暂不可放置。放置失败时，可尝试靠近空闲芽点、改变方向、避开其他枝条，或先收集足够资源。

## 常见问题

**双击 EXE 无法进入游戏？**  
先确认发布包已完整解压，EXE 与同名 PCK 位于同一目录；更新版本时请同时替换这两个文件。

**下载仓库 ZIP 后找不到 EXE？**  
仓库保存源码，EXE/PCK 已被 `.gitignore` 排除。请使用 Releases 中的发布包，或按上方步骤用 Godot 运行源码。

**刚放下的枝条不能继续接枝？**  
新枝条需要等翻页后成熟，其芽点才会开放。

**镜头拖远后找不到树或资源？**  
双击中键回到初始视角。资源在当天生成后固定在世界中，移动镜头不会刷新资源。

## 工程入口

- `project.godot`：Godot 项目文件。
- `scenes/opening/book_opening.tscn`：完整游戏入口。
- `scenes/main.tscn`：核心游戏场景。
- `config/opening.tres`：封面、视频和开场参数。
- `config/story.tres`：故事页配置。
- `config/mvp.tres`：游戏节奏、素材和玩法参数。

`.godot/` 缓存、发布包、本地工具和凭据文件不纳入版本管理；素材的 `.import` 设置与脚本 `.uid` 文件会保留。
